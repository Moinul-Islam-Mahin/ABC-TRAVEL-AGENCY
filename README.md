# ABC Travel Agency

A Java GUI application for booking tours, built as a university course project.

## Features
- Browse tours with cost, room type, tour duration and location
- Book a tour based on the chosen options
- Generate a receipt for every booking
- Tour and booking data are stored in files

## Tech Stack
- Java (GUI)
- File-based storage

## How to Run
1. Clone the repository.
2. Open the `final project` folder in a Java IDE (NetBeans, IntelliJ or Eclipse).
3. Run the main class.
